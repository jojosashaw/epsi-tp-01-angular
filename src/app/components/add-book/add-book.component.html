Ajouter un livre

Le titre est requis. Le titre doit avoir au moins 3 caractères.
L'auteur est requis. L'auteur doit avoir au moins 3 caractères.
La description est requise. La description doit avoir au moins 10 caractères.
La catégorie est requise.
La note est requise. La note doit être supérieure ou égale à 1. La note doit être inférieure ou égale à 5.
